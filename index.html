What Atlas is (in one sentence)

Atlas is the place inside Diligent IQ where Blue Ops consultants publish finished offline analysis packages (HTML dashboards) so entitled clients can open them securely — instead of emailing files or hosting them on an unsecured public site.

Project ID 2026-1 Charter start 10 Aug 2026 Today = end of Sprint 3 V1 scope locked 15 Sep Production build not started
Problem we solve Analyses are prepared offline (Reid / Blue Ops). V1 is how we get a finished package into Diligent IQ with security, versioning, and a client experience.
What V1 is not Not a live query engine. Not an HTML editor. Not a marketplace/checkout. Not Directus as the V1 control plane (deferred to V2).
North-star date 1–3 pilot analyses usable for clients ahead of Diligent IQ external launch (~1 Dec). Internal production smoke before that.
Suggested 30-minute flow: 0–3 Context · 3–10 Plan · 10–18 Design / ownership · 18–25 Sign-off & gates · 25–30 Next steps & decisions. Pause for questions after each block; do not demo deep UI unless asked.

What “done enough” looks like for V1

  • Consultant opens Atlas Studio inside a Diligent IQ project and sees analysis cards (draft / published / retracted).
  • Creates an analysis shell, binds one or more projects they can access (current project default; multi-select allowed).
  • Uploads one standalone HTML file as an immutable version; validation blocks unsafe / invalid packages.
  • Previews the exact client landing page + HTML before publish.
  • Publishes once to all bound projects; clients see only published active version; no drafts, no Manage.
  • Can replace (stage then activate) and retract without deleting history.
  • Security reuses Diligent IQ project membership — Atlas does not invent a second entitlement system.
